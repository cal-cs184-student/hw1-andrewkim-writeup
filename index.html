Task 1: Drawing Single-Color Triangles

Rasterization is the process of taking some 3D geometric object that we want to sample and converting it to the 2D screen we want to display it on. We are essentially “flattening” the object, and we can do so by breaking it down into many triangles to display.

In order to rasterize a single triangle, we iterate through each pixel on the screen and determine whether or not it lies inside the triangle through a binary process: if it does, we fill in that pixel, and if it doesn’t, we don’t, constructing the triangle pixel by pixel. To do this, we use the help of what is called the Point-in-Triangle Test. In this test, each edge of the triangle defines what are called half-planes where the triangle itself is the intersection of three half-planes. For each edge, we determine which side a pixel lies using a mathematical formula that returns a positive number if the pixel is “inside” the edge, a negative number if the pixel is “outside” the edge, and 0 if it lies on the edge. A pixel that lies on an edge is considered inside the triangle. If all three edges collectively return a number >= 0 or <= 0 (depending on the winding order of the vertices), then that pixel is inside the triangle.

To make the process more efficient, my algorithm only checks each sample within the bounding box of the triangle, which is the smallest rectangle that can be drawn around the triangle while ensuring the entire triangle is inside it. To find the bounding box, I pulled the minimum and maximum x and y values out of the three vertices given to define the corners of the box. Then, I created a nested loop to iterate through its rows and columns, determining each pixel’s location relative to the triangle and filling them in appropriately. This process uses a helper function that implements the binary process and the Point-in-Triangle Test described above. Since my algorithm checks each sample within the bounding box once, it can therefore be no worse than any algorithm that checks each sample within the bounding box of a given triangle.
